## 摘要
预训练视觉语言模型（VLMs）的分类准确率高度依赖于文本提示（text prompts）的质量。手工设计的模板和由大语言模型（LLM）生成的描述不仅使预测更具可解释性，还允许在异构 VLM 之间重用相同的提示。近期的研究利用少量标注图像构建任务自适应的文本提示。然而，现有的少样本（few-shot）文本提示方法在构建提示时并未明确关注被错误分类的样本，导致即使在样本数量增加时，性能提升也微乎其微。为了充分利用少样本监督，我们提出了文本提示增强（Text Prompt Boosting, TPB），这是一个受 AdaBoost 启发的框架，它将每个基于文本提示的分类器视为弱学习器，并通过明确针对困难的、被错误分类的样本，将它们顺序聚合为一个强集成模型。大量实验表明，TPB 在文本空间中保留了任务固有且与模型无关的线索，从而实现了鲁棒的跨模型迁移。在 11 个分类基准测试中，TPB 提高了源模型的准确率，并在迁移到更大、更强大的 VLM 时保留了由样本驱动的增益，而现有方法在这些情况下难以维持此类改进。

## Abstract
The classification accuracy of pretrained Vision-Language Models (VLMs) relies on the quality of the text prompts. Handcrafted templates and Large Language Model (LLM)-generated descriptions not only make predictions more interpretable, but also enable reuse of the same prompts across heterogeneous VLMs. Recent works construct task-adapted text prompts with a small number of labeled images. However, existing few-shot text prompting methods do not explicitly focus on misclassified examples during prompt construction, leading to only marginal improvements even as more shots become available. To fully exploit few-shot supervision, we propose Text Prompt Boosting (TPB), an AdaBoost-inspired framework that treats each text-prompt-based classifier as a weak learner and sequentially aggregates them into a strong ensemble by explicitly targeting hard, misclassified examples. Extensive experiments show that TPB preserves task-intrinsic, model-agnostic cues in text space, enabling robust cross-model transfer. Across eleven classification benchmarks, TPB improves accuracy on the source model and preserves shot-driven gains when transferred to larger, more capable VLMs, where existing methods struggle to sustain such improvements.

*   **核心问题**：如何有效利用极少量的标注数据（Few-shot）来优化视觉语言模型（VLM，如 CLIP）的文本提示词，并确保这些提示词在不同模型间具有良好的迁移性。
*   **研究背景**：
    *   VLM 的性能高度依赖提示词质量。
    *   **软提示（Soft Prompting）**：通过反向传播优化连续向量，效果好但不可读且无法跨模型迁移。
    *   **硬提示（Hard Prompting）**：使用自然语言，可解释且可迁移，但现有方法在增加样本数（Shot）时性能提升缓慢（饱和快），且未能充分利用误分类样本的信息。
*   **动机**：借鉴经典机器学习中的集成学习思想，通过聚焦“困难样本”来打破性能瓶颈。

### 2. 方法论：Text Prompt Boosting (TPB)
*   **核心思想**：将每一个基于文本提示的分类器视为一个“弱学习器”，利用 **AdaBoost (具体为 SAMME.R 算法)** 框架，通过多轮迭代，每一轮都增加上一轮预测错误样本的权重，最终将多个弱分类器聚合成一个强分类器。
*   **关键技术细节**：
    *   **大规模提示池构建**：整合手工模板、LLM 生成的描述以及它们的组合，形成丰富的候选空间。
    *   **贪婪提示组合 (GPC)**：作为弱学习器的训练算法。分为两步：
        1.  **单模板初始化**：从 80 个 CLIP 模板中选出加权误差最小的一个。
        2.  **类级别贪婪插入**：循环遍历每个类别，从提示池中选择能最大程度降低当前加权误差的提示词加入该类的“提示库”。
    *   **提示词复制（Duplication）**：在离散空间中通过重复添加同一个提示词来模拟连续权重的调整，增强特定语义的影响力。
    *   **图像增强（Augmentation）**：在 Boosting 循环中对少样本数据进行随机裁剪和翻转，防止集成模型过快过拟合极少数样本。

### 3. 实验设计
*   **数据集**：涵盖 11 个标准图像分类基准，包括 ImageNet-1K、Caltech101（通用）、OxfordPets、StanfordCars、FGVCAircraft（细粒度）、SUN397（场景）、DTD（纹理）、EuroSAT（卫星）、UCF101（动作）等。
*   **对比方法**：
    *   **零样本基准**：CLIP 原生提示、DCLIP、CuPL。
    *   **少样本/提示优化基准**：CoOp（软提示）、PEZ（梯度优化硬提示）、LLMbo（黑盒优化）、ProAPO（进化搜索优化）。
    *   **迁移基准**：结合了 EFT（仿真微调）的 CoOp 和 PromptSRC。
*   **Benchmark 设置**：在源模型（如 CLIP RN50 或 ViT-B/32）上训练，并在 1-16 shot 场景下评估，同时测试其向更大模型（ViT-L/H/G/E 等）的迁移效果。

### 4. 资源与算力
*   **硬件使用**：使用了单张 **NVIDIA RTX 3090 (24GB)**。对于内存需求更高的配置，使用了 **RTX A6000 (48GB)**。
*   **训练时长**：文中未明确给出具体的总训练小时数，但提到 Boosting 轮数通常为 30-50 轮，且由于是基于冻结的 VLM 提取特征，计算开销主要集中在特征比对和权重更新上，而非深度神经网络的反向传播。
*   **推理开销**：推理时文本嵌入可预计算，仅需一次图像编码器前向传播，延迟极低。

### 5. 实验数量与充分性
*   **实验规模**：非常充分。
    *   横跨 **11 个数据集**，涵盖了从 1 到 16 shot 的多种设置。
    *   测试了 **2 个源模型**和超过 **10 个目标模型**（包括 OpenCLIP, SigLIP2, EVA-02, MetaCLIP2 等不同架构和训练数据）。
    *   进行了详尽的**消融实验**：包括增强因子 $a$、提示池多样性、Boosting 轮数 $M$、提示词复制的影响等。
*   **客观性**：所有实验均取 3 个随机种子的平均值，并提供了标准差，对比基准涵盖了当前最先进的同类方法。

### 6. 主要结论与发现
*   **可扩展性**：TPB 在源模型上的表现随 Shot 增加而显著提升，克服了以往硬提示方法“出分即巅峰”的饱和问题。
*   **迁移鲁棒性**：TPB 生成的提示词在迁移到更大模型时，能保持甚至放大在源模型上获得的增益。
*   **自然语言的重要性**：实验发现，像 PEZ 这种通过梯度优化出的“乱码”提示词虽然在源模型表现好，但迁移性极差；而 TPB 保持了人类可读的自然语言，迁移效果极佳。
*   **Boosting 的作用**：迭代重采样/重加权比单纯的数据增强更能捕捉任务相关的、模型无关的特征。

### 7. 优点
*   **性能与迁移的双赢**：在保持硬提示可解释性和迁移性的同时，达到了接近甚至在迁移场景下超过软提示的性能。
*   **即插即用**：不需要对目标模型进行任何微调，仅通过文本重嵌入即可实现跨架构迁移。
*   **算法优雅**：将经典的 AdaBoost 成功引入现代 VLM 提示优化领域，解决了少样本分布覆盖不足的问题。

### 8. 不足与局限
*   **构建成本**：在类别数量极多（如数千类）的大规模数据集上，贪婪搜索提示词的计算成本会显著增加。
*   **噪声敏感性**：AdaBoost 算法天生对噪声标签敏感，如果少样本数据中存在标注错误，TPB 可能会过度关注这些噪声样本。
*   **提示池依赖**：性能上限受限于初始提示池的质量和多样性，对于极其冷门或专业的领域，如果 LLM 无法生成准确描述，效果可能受限。
