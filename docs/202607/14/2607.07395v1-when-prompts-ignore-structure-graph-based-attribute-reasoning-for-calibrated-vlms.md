## 摘要
可靠的置信度估计仍然是视觉语言模型（VLMs）测试时自适应的一个关键局限。在这些模型中，提示微调虽然提高了零样本准确率，但往往由于熵驱动的过度自信而导致校准性能下降。先前的方法利用大语言模型（LLM）生成的类别属性和对比正则化来缓解这一问题，但它们将属性视为相互独立的，忽略了其关联结构。我们提出了 ARGTCA，它将（类别，属性）对表示为符号属性图中的节点，并使用对比目标训练图注意力网络（GAT），以生成捕捉属性间依赖关系的结构化嵌入。我们引入了两种属性选择策略：用于类内多样性的 ARGTCA-DIV 和用于类间辨别性的 ARGTCA-DISC。在九个基准测试上的实验表明，ARGTCA-DIV 相比基线方法将平均预期校准误差（ECE）降低了约 37%，而 ARGTCA-DISC 表现稳健，作为次优变体，将平均 ECE 降低了约 17%。这些结果表明，对符号属性交互进行建模为实现可靠的视觉语言模型测试时自适应提供了一种原则性方法。

## Abstract
Reliable confidence estimation remains a key limitation of test-time adaptation in vision-language models (VLMs), where prompt tuning improves zero-shot accuracy but often degrades calibration due to entropy-driven overconfidence. Prior approaches mitigate this using LLM-derived class attributes and contrastive regularization, yet treat attributes independently, ignoring their relational structure. We propose ARGTCA, which represents (class, attribute) pairs as nodes in a Symbolic Attribute Graph and trains a Graph Attention Network (GAT) using contrastive objectives to produce structurally informed embeddings that capture inter-attribute dependencies. We introduce two attribute selection strategies: ARGTCA-DIV for intra-class diversity and ARGTCA-DISC for inter-class discrimination. Experiments across nine benchmarks show that ARGTCA-DIV reduces average Expected Calibration Error (ECE) by approximately ~37% over baselines, while ARGTCA-DISC consistently performs as the second-best variant, reducing average ECE by approximately ~17% over baselines. These results suggest that modeling symbolic attribute interactions provides a principled approach for reliable test-time adaptation in VLMs.

### 1. 核心问题与整体含义（研究动机和背景）
视觉语言模型（VLM，如 CLIP）在执行测试时自适应（Test-Time Adaptation, TTA）时，通常采用提示微调（Prompt Tuning）来提升零样本准确率。然而，现有的方法（如 TPT）主要依赖熵最小化目标，这会导致模型产生**过度自信**的预测，从而使模型在概率预测上失去可靠性（即校准性能退化，ECE 误差升高）。

虽然近期研究（如 TCA）引入了 LLM 生成的属性来辅助校准，但它们将属性视为独立的集合，忽略了属性间的**结构化关系**。这导致了两个问题：
*   **类内冗余**：选中的属性可能是近义词（如“粗糙的”和“凹凸不平的”），在嵌入空间中过于聚集。
*   **类间混淆**：某些属性在不同类别间共有（如“哺乳动物”），缺乏区分度。
本论文旨在通过建模属性间的图结构关系来解决这些问题，实现更精准的模型校准。

### 2. 方法论：ARGTCA 框架
论文提出了 **ARGTCA**（基于属性关系图的测试时校准自适应），分为两个阶段：

*   **阶段 1：符号属性图（SAG）构建与 GAT 训练（离线）**
    *   **节点初始化**：将（类别，属性）对作为图节点，使用 CLIP 文本编码器提取初始嵌入。
    *   **边定义**：建立两种边：**类内边**（连接属于同一类别的所有属性节点）和**类间边**（连接在不同类别中共享相同名称的属性节点）。
    *   **图注意力网络（GAT）**：利用 GAT 在图中传播结构信息。通过**有监督对比损失（SupCon）**进行训练，使同类属性在结构空间中更紧凑，异类属性更具区分度。
*   **阶段 2：属性选择策略与测试时微调**
    基于训练好的图嵌入，提出两种选择策略：
    *   **ARGTCA-DIV（多样性策略）**：选择类内语义最互补（余弦相似度最低）的属性对，以提供更丰富的梯度信号。
    *   **ARGTCA-DISC（判别性策略）**：选择与其它类别节点平均角度距离最大的属性，以增强类间区分度。
    *   **微调**：选定的属性用于初始化提示，在测试时对单个图像进行单步梯度更新。

*   **零测试成本**：通过离线预处理和高效的图推理，在不增加在线延迟的情况下提升了性能。
