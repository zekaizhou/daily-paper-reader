## 摘要
预训练视觉语言模型（VLM）的分类准确率依赖于文本提示的质量。手工设计的模板和大型语言模型（LLM）生成的描述不仅使预测更具可解释性，还允许在异构 VLM 之间重用相同的提示。最近的研究利用少量标注图像构建任务自适应的文本提示。然而，现有的少样本（few-shot）文本提示方法在构建提示时并未明确关注被错误分类的样本，导致即使在样本数量增加时，改进也微乎其微。为了充分利用少样本监督，我们提出了文本提示提升（Text Prompt Boosting, TPB），这是一个受 AdaBoost 启发的框架，它将每个基于文本提示的分类器视为弱学习器，并通过明确针对困难的、被错误分类的样本，将它们顺序聚合为一个强集成模型。大量实验表明，TPB 在文本空间中保留了任务固有且与模型无关的线索，从而实现了鲁棒的跨模型迁移。在 11 个分类基准测试中，TPB 提高了源模型的准确率，并在迁移到更大、更强大的 VLM 时保留了由样本驱动的增益，而现有方法在这些情况下难以维持此类改进。

## Abstract
The classification accuracy of pretrained Vision-Language Models (VLMs) relies on the quality of the text prompts. Handcrafted templates and Large Language Model (LLM)-generated descriptions not only make predictions more interpretable, but also enable reuse of the same prompts across heterogeneous VLMs. Recent works construct task-adapted text prompts with a small number of labeled images. However, existing few-shot text prompting methods do not explicitly focus on misclassified examples during prompt construction, leading to only marginal improvements even as more shots become available. To fully exploit few-shot supervision, we propose Text Prompt Boosting (TPB), an AdaBoost-inspired framework that treats each text-prompt-based classifier as a weak learner and sequentially aggregates them into a strong ensemble by explicitly targeting hard, misclassified examples. Extensive experiments show that TPB preserves task-intrinsic, model-agnostic cues in text space, enabling robust cross-model transfer. Across eleven classification benchmarks, TPB improves accuracy on the source model and preserves shot-driven gains when transferred to larger, more capable VLMs, where existing methods struggle to sustain such improvements.

### 2. 论文提出的方法论：Text Prompt Boosting (TPB)
*   **核心思想**：借鉴经典集成学习算法 **AdaBoost**，将每一组文本提示定义的分类器视为一个“弱学习器”。通过多轮迭代，每一轮都显式地增加被前一轮误分类样本（困难样本）的权重，从而迫使模型学习能够覆盖更多视觉变体的提示词，最后将多个弱学习器聚合成一个强分类器。
*   **关键技术细节**：
    1.  **大提示池构建**：整合手工模板、LLM 生成的描述以及它们的组合，形成丰富的离散提示候选空间。
    2.  **贪婪提示组合 (GPC)**：作为弱学习器。它分为两个阶段：首先选择一个最佳的共享模板初始化；然后针对每个类别，贪婪地从提示池中选择能最大程度降低当前加权误差的提示词。
    3.  **提示重复（Prompt Duplication）**：在离散空间中通过允许重复选择同一个提示词来模拟连续权重的效果，增强特定提示的影响力。
    4.  **图像增强（Augmentation）**：在 Boosting 循环中对少样本数据进行随机增强，防止集成模型过快地“背诵”原始样本，确保每一轮都有新的“困难”视角供模型学习。
    5.  **SAMME.R 算法集成**：采用 AdaBoost 的多分类实值版本，通过对数概率输出进行加权聚合。

### 6. 主要结论与发现
*   **Shot 可扩展性**：TPB 显著优于现有的硬提示方法。随着 Shot 增加，TPB 的准确率稳步提升，而 ProAPO 等方法很快陷入停滞。
*   **迁移鲁棒性**：TPB 生成的提示词是纯自然语言，具有模型无关性。在迁移到更大规模的异构 VLM 时，TPB 不仅能保持增益，甚至能展现出比在源模型上更强的性能。
*   **困难样本攻克**：通过可视化证明，TPB 的后续轮次确实能捕捉到初次分类失败的特征（如被遮挡的部位或特定的行为描述）。
*   **自然语言的重要性**：实验发现，只有保持提示词的“人类可读性”和“语义连贯性”，才能确保跨模型的迁移效果。

### 7. 优点
*   **可解释性**：生成的提示词是人类可读的自然语言描述。
*   **高效迁移**：无需针对目标模型重新训练，仅需重新计算文本嵌入，且推理延迟低。
*   **算法创新**：成功将经典的 AdaBoost 思想引入 VLM 提示词优化领域，解决了少样本利用率低的问题。
*   **即插即用**：不改变 VLM 的权重，适用于任何 CLIP 架构的模型。

### 8. 不足与局限
*   **构建成本**：在类别数量极大的数据集上，GPC 搜索提示词的计算开销会随之增加。
*   **噪声敏感性**：AdaBoost 机制可能会过度关注标注错误的样本或极端的离群值（Outliers）。
*   **提示池依赖**：性能上限受限于初始提示池的质量和多样性，如果池中缺乏描述细粒度差异的词汇，模型提升空间受限。
*   **超参数调节**：Boosting 轮数和增强因子等超参数可能需要针对不同领域进行微调。
