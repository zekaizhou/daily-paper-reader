## 摘要
视觉-语言-动作 (VLA) 模型在环境偏移（例如相机位姿的变化以及向不同但相似的机器人（如从 Panda 到 UR5e）的迁移）下，往往无法执行相同的已学习任务。将这些模型适配到偏移后的环境（即目标领域）通常需要针对每个任务训练多个演示，而这些演示的收集成本很高。为了减轻数据整理和训练的负担，我们提出了一种基于类比的方法，通过权重向量算术并添加特定领域信息来使 VLA 模型适应环境偏移，命名为领域算术 (DART)。与以往的方法不同，DART 仅需收集单个演示，从而实现了高效适配。为了准确隔离用于添加的特定领域信息，DART 在权重向量的奇异分量之间进行子空间对齐，以过滤掉噪声分量。在模拟和真实世界的实验中，DART 在各种视觉和具身偏移的单样本场景下均优于现有的 VLA 适配方法。代码可在 https://github.com/snumprlab/dart 获取。

## Abstract
Vision-Language-Action (VLA) models often fail to perform the same learned tasks under environmental shifts, such as changes in camera pose and shifts to a different but similar robot (e.g., from Panda to UR5e). Adapting these models to the shifted environment (i.e., target domain) often requires training on multiple demonstrations for each task, which are costly to collect. To reduce the burden of data curation and training, we propose an analogy-based method that adapts VLA models under environmental shifts through weight vector arithmetic with domain-specific information addition, named Domain ARiThmetic (DART). Unlike prior approaches, DART requires collecting only a single demonstration, enabling efficient adaptation. To accurately isolate domain-specific information for addition, DART performs subspace alignment between singular components in weight vectors to filter out noisy components. In both simulated and real-world experiments, DART outperforms existing VLA adaptation methods in one-shot scenarios across diverse visual and embodiment shifts. Code is available at https://github.com/snumprlab/dart.

### 1. 核心问题与整体含义
*   **研究背景**：视觉-语言-动作（VLA）模型虽然在大型数据集上表现优异，但在实际部署时面临“环境偏移”（Environmental Shifts）的严峻挑战，如相机位姿改变、光照变化或机器人硬件（具身）的更换。
*   **核心痛点**：现有的适配方法通常需要针对每个任务收集大量演示数据进行微调，这在实际应用（如家庭环境）中成本极高且效率低下。
*   **研究动机**：探索是否能通过极少量的数据（单样本/One-shot）实现模型对新环境的快速适配，同时保留模型原有的多任务处理能力。

### 2. 方法论：DART (Domain ARiThmetic)
*   **核心思想**：受语言模型中“权重算术”（如 queen = king + woman - man）的启发，DART 假设 VLA 模型的权重更新可以线性分解为**任务特定方向**和**领域特定方向**。
*   **关键技术细节**：
    1.  **领域向量提取**：首先在源域和目标域上分别对同一任务进行单样本微调，得到更新向量 $\Delta_{m,src}$ 和 $\Delta_{m,tgt}$。通过减法 $\delta_{tgt} = \Delta_{m,tgt} - \Delta_{m,src}$ 抵消任务相关信息，隔离出环境偏移信息。
    2.  **子空间过滤 (Subspace Filtering)**：利用奇异值分解 (SVD) 提取权重更新的低秩结构。通过计算源域和目标域更新向量的子空间对齐能量，过滤掉仅属于源域的噪声分量，确保提取的领域向量更纯净。
    3.  **子空间缩放 (Subspace Scaling)**：根据子空间对齐得分 $\gamma$ 对领域向量进行加权，自动下调那些对齐程度低、可能包含较多噪声的层更新。
    4.  **模型注入**：将精炼后的领域向量加回到原始基座模型中：$\theta^* = \theta_0 + \alpha \cdot \tilde{\delta}_{tgt}$，其中 $\alpha$ 为缩放系数。
