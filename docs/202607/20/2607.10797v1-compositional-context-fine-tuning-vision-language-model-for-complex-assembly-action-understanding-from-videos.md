## 摘要
装配动作理解是实现高效人机协作装配的关键，但由于细微的动作和细粒度的手物交互，这仍然具有挑战性。我们通过组合上下文微调（CCFT）将视觉语言模型（VLM）应用于这一具有挑战性的领域，该方法将装配动作分解为语义元素（动词、物体、工具），并利用模板化的问答对微调 VLM 以识别每个动作元素。这种方法确保了近乎确定性的输出。为了在有限数据下实现高效且有效的多任务学习，本文提出了一种层分区交替训练（LP-AT）方法，该方法通过特定元素的低秩适配器分配不同的模型层来识别特定的动作元素。LP-AT 在特定元素的适配器之间交替更新权重，在减少跨任务干扰的同时，实现了针对每个适配器的超参数优化。此外，我们基于现有的装配视频数据集创建了 HA-ViD-VQA 和 IKEA-ASM-VQA 数据集。在这些数据集上的广泛实验表明，我们的方法始终优于强大的动作识别基线模型，同时提供可解释的元素级预测，能够支持多种下游应用。

## Abstract
Assembly action understanding is a key enabler for effective human-robot collaborative assembly, yet it remains challenging due to subtle motions and fine-grained hand-object interactions. We adapt vision-language models (VLMs) to this challenging domain with Compositional Context Fine-Tuning (CCFT), a method that decomposes assembly actions into semantic elements (Verb, Object, Tool) and fine-tunes VLMs to recognize each action element using templated question-answering pairs. This approach ensures near-deterministic outputs. To enable efficient and effective multi-task learning under limited data, a Layer-Partitioned Alternating Training (LP-AT) method is presented, which assigns distinct model layers to recognize specific action elements through element-specific low-rank adapters. LP-AT alternates weight updates across element-specific adapters, reducing cross-task interference while enabling per-adapter hyperparameter optimization. Furthermore, we create HA-ViD-VQA and IKEA-ASM-VQA datasets from existing assembly video datasets. Extensive experiments on these datasets demonstrate that our method consistently outperforms strong action recognition baselines while providing interpretable element-level predictions that can support diverse downstream applications.

### 1. 核心问题与研究动机
*   **核心问题**：在人机协作（HRC）装配场景中，如何让视觉语言模型（VLM）精确理解复杂的装配动作。
*   **研究背景**：装配动作包含细微的运动、相似的动作模式以及复杂的手物交互。传统的视频动作识别模型缺乏语义推理能力，而通用的 VLM 虽然推理能力强，但在特定工业领域存在输出不确定（幻觉）、缺乏可解释性以及在有限数据下多任务学习效率低的问题。

### 2. 方法论
论文提出了两个核心技术组件：
*   **组合上下文微调（CCFT）**：
    *   **核心思想**：将复杂的整体动作分解为三个语义要素：**动词（Verb）**、**操作对象（Object）**和**工具（Tool）**。
    *   **技术细节**：通过模板化的视觉问答（VQA）对模型进行微调。例如，询问“视频中的动作动词是什么？”，模型输出预定义的自然语言标签。这种方法将生成式任务转化为受限空间下的判别任务，确保了输出的近确定性。
*   **层分区交替训练（LP-AT）**：
    *   **核心思想**：针对不同的语义要素，在 VLM 的不同层级应用独立的低秩适配器（LoRA）。
    *   **算法流程**：将 VLM 的语言解码器层划分为不相交的组（如前几层负责动词，中间层负责对象）。在训练时，采用交替优化策略：在一个 epoch 内，依次针对每个子任务更新其对应的 LoRA 权重并合并回基座模型。这减少了多任务学习中的参数干扰，并允许为不同任务设置不同的超参数（如学习率、LoRA 秩）。

### 6. 主要结论与发现
*   **性能领先**：CCFT 方法在所有数据集和视角下均显著优于传统的强动作识别基线模型。
*   **任务复杂度差异**：工具识别准确率最高（视觉特征明显），动词识别在微观装配中优于对象识别，但在宏观家具组装中则相反。
*   **LP-AT 的必要性**：简单的顺序训练或独立训练合并会导致严重的性能下降（灾难性遗忘或参数冲突），而交替训练能保持各任务的兼容性。

### 7. 亮点与优点
*   **可解释性**：通过分解动作要素，模型不仅给出结果，还能解释识别出的具体动词和工具，这对工业安全审计至关重要。
*   **确定性输出**：利用模板化 VQA 克服了 VLM 常见的幻觉问题，使其更符合工业应用对低容错率的要求。
*   **参数高效**：LP-AT 策略在有限数据下实现了多任务的深度定制，且无需全参数微调。

### 8. 不足与局限
*   **实时性挑战**：虽然使用了 LoRA，但基于 7B 参数量的 VLM 进行视频推理，在实时人机协作（毫秒级响应）中可能仍存在计算延迟。
*   **层分区策略较主观**：目前层分配（如 10:14:4）主要基于经验和启发式规则，缺乏自动化的最优分配理论支撑。
*   **视觉特征受限**：由于冻结了视觉编码器，模型对特定装配细节（如极小的螺丝）的感知完全依赖于预训练特征，可能存在感知瓶颈。
*   **组合逻辑简单**：目前最终动作的合成仅靠字符串拼接，缺乏更高级的逻辑推理来纠正单个要素识别错误导致的整体失败。
