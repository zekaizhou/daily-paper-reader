## 摘要
可靠的置信度估计仍然是视觉语言模型（VLMs）测试时自适应的一个关键局限。在这些模型中，提示微调虽然提高了零样本准确率，但往往由于熵驱动的过度自信而导致校准性能下降。先前的方法通过使用大语言模型（LLM）生成的类别属性和对比正则化来缓解这一问题，但它们将属性视为相互独立的，忽略了其关联结构。我们提出了 ARGTCA，它将（类别，属性）对表示为符号属性图中的节点，并使用对比目标训练图注意力网络（GAT），以生成捕捉属性间依赖关系的结构化嵌入。我们引入了两种属性选择策略：用于类内多样性的 ARGTCA-DIV 和用于类间辨别性的 ARGTCA-DISC。在九个基准测试上的实验表明，ARGTCA-DIV 相比基准方法将平均预期校准误差（ECE）降低了约 37%，而 ARGTCA-DISC 表现稳健，作为次优变体，将平均 ECE 降低了约 17%。这些结果表明，对符号属性交互进行建模为视觉语言模型中可靠的测试时自适应提供了一种原则性方法。

## Abstract
Reliable confidence estimation remains a key limitation of test-time adaptation in vision-language models (VLMs), where prompt tuning improves zero-shot accuracy but often degrades calibration due to entropy-driven overconfidence. Prior approaches mitigate this using LLM-derived class attributes and contrastive regularization, yet treat attributes independently, ignoring their relational structure. We propose ARGTCA, which represents (class, attribute) pairs as nodes in a Symbolic Attribute Graph and trains a Graph Attention Network (GAT) using contrastive objectives to produce structurally informed embeddings that capture inter-attribute dependencies. We introduce two attribute selection strategies: ARGTCA-DIV for intra-class diversity and ARGTCA-DISC for inter-class discrimination. Experiments across nine benchmarks show that ARGTCA-DIV reduces average Expected Calibration Error (ECE) by approximately ~37% over baselines, while ARGTCA-DISC consistently performs as the second-best variant, reducing average ECE by approximately ~17% over baselines. These results suggest that modeling symbolic attribute interactions provides a principled approach for reliable test-time adaptation in VLMs.

*   **核心问题**：视觉语言模型（VLM，如 CLIP）在进行**测试时自适应（Test-Time Adaptation, TTA）**时，虽然通过提示微调（Prompt Tuning）提升了分类准确率，但往往会导致模型**过度自信（Overconfidence）**，从而显著降低预测的校准度（Calibration）。
*   **研究背景**：先前的方法（如 TCA）尝试引入 LLM 生成的属性来辅助校准，但它们将属性视为“扁平的集合”，忽略了属性之间的结构关系（例如：某些属性在不同类别间是通用的，而某些属性在类内是冗余的）。这种结构信息的缺失导致文本特征空间的几何分布不够理想，进而影响校准效果。

### 2. 方法论：ARGTCA 框架
ARGTCA 的核心思想是通过**符号属性图（Symbolic Attribute Graph, SAG）**来建模属性间的关系，并利用图神经网络优化属性选择。
*   **核心流程**：
    1.  **图构建（SAG）**：将（类别, 属性）对作为节点。定义两种边：**类内边**（连接同类别的不同属性）和**类间边**（连接不同类别但名称相同的属性，如“哺乳动物”同时连接豹子和海豚）。
    2.  **图注意力网络（GAT）训练**：使用 GAT 传播结构信息。采用**监督对比学习损失（SupCon Loss）**进行离线训练，使同类属性在嵌入空间更紧凑，异类属性更疏离。
    3.  **属性选择策略**：
        *   **ARGTCA-DIV（多样性）**：选择类内语义互补性最强（余弦相似度最低）的属性对，以提供更丰富的梯度信号。
        *   **ARGTCA-DISC（判别性）**：选择与其他类别节点角距离最大的属性，增强类间区分度。
    4.  **测试时微调**：利用选出的属性初始化提示，在测试阶段对单个样本进行单步梯度更新（最小化熵及对比正则化损失）。

### 6. 主要结论与发现

### 7. 优点与亮点
*   **结构化视角**：首次将符号化的属性关系引入 VLM 的测试时校准，弥补了先前方法忽略语义结构的缺陷。

*   **鲁棒性**：在纹理分类（DTD）和细粒度分类等极易混淆的场景下表现尤为突出。

### 8. 不足与局限
*   **对 LLM 的依赖**：方法的效果受限于 LLM 生成属性的质量。如果 LLM 在某些特定领域（如医学或专业卫星图像）生成的属性不准确，模型性能可能受损。

*   **数据集依赖性**：图结构和 GAT 训练是针对每个数据集独立进行的，目前尚不支持跨数据集的零样本迁移（即新数据集仍需运行简短的离线第一阶段）。
