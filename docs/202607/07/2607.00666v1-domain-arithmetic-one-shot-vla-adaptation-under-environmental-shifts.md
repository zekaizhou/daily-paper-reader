## 摘要
视觉-语言-动作 (VLA) 模型在环境偏移（例如相机位姿变化以及向不同但相似的机器人迁移，如从 Panda 到 UR5e）下，往往无法执行相同的已学习任务。将这些模型适配到偏移后的环境（即目标域）通常需要针对每个任务在多个演示上进行训练，而这些演示的收集成本很高。为了减轻数据整理和训练的负担，我们提出了一种基于类比的方法，通过权重向量算术并添加特定领域信息，在环境偏移下适配 VLA 模型，命名为领域算术 (Domain ARiThmetic, DART)。与以往的方法不同，DART 仅需收集单个演示，从而实现了高效适配。为了准确隔离用于添加的特定领域信息，DART 在权重向量的奇异分量之间进行子空间对齐，以过滤掉噪声分量。在模拟和真实世界的实验中，DART 在各种视觉和具身偏移的单样本场景下均优于现有的 VLA 适配方法。代码可在 https://github.com/snumprlab/dart 获取。

## Abstract
Vision-Language-Action (VLA) models often fail to perform the same learned tasks under environmental shifts, such as changes in camera pose and shifts to a different but similar robot (e.g., from Panda to UR5e). Adapting these models to the shifted environment (i.e., target domain) often requires training on multiple demonstrations for each task, which are costly to collect. To reduce the burden of data curation and training, we propose an analogy-based method that adapts VLA models under environmental shifts through weight vector arithmetic with domain-specific information addition, named Domain ARiThmetic (DART). Unlike prior approaches, DART requires collecting only a single demonstration, enabling efficient adaptation. To accurately isolate domain-specific information for addition, DART performs subspace alignment between singular components in weight vectors to filter out noisy components. In both simulated and real-world experiments, DART outperforms existing VLA adaptation methods in one-shot scenarios across diverse visual and embodiment shifts. Code is available at https://github.com/snumprlab/dart.

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：Vision-Language-Action (VLA) 模型虽然在源域表现强劲，但在面对环境偏移（如相机角度变化、光照改变、机器人硬件更换）时性能会剧烈下降。
*   **核心挑战**：现有的适配方法通常需要为每个任务收集大量目标域的专家演示数据，这在实际部署（如家庭环境）中成本极高且不可行。
*   **核心问题**：能否仅通过**单个任务的一次演示（One-shot）**，就让 VLA 模型在新的环境中恢复其所有已学习任务的处理能力？

### 2. 方法论：领域算术 (DART)
*   **核心思想**：基于“权重算术（Weight Arithmetic）”的类比原理。作者发现 VLA 模型的权重更新可以分解为相互独立的“任务方向”和“领域方向”。通过简单的向量减法，可以从单样本微调的权重中提取出纯粹的“领域向量”，并将其加回原始模型。
*   **关键技术细节**：
    1.  **领域向量提取**：计算目标域单样本微调后的更新向量 $\Delta_{tgt}$ 和源域相同任务的更新向量 $\Delta_{src}$。通过 $\delta = \Delta_{tgt} - \Delta_{src}$ 抵消掉任务相关的成分，隔离出环境偏移成分。
    2.  **子空间过滤 (Subspace Filtering)**：利用奇异值分解 (SVD) 分析更新向量。为了防止源域的噪声干扰，DART 只保留 $\Delta_{src}$ 中与 $\Delta_{tgt}$ 几何对齐程度高的基向量进行减法操作。
    3.  **子空间缩放 (Subspace Scaling)**：根据两个更新向量的子空间对齐得分（Alignment Score）动态调整领域向量的权重，降低低质量更新的影响。
    4.  **模型注入**：将精炼后的领域向量乘以缩放系数 $\alpha$ 后加回基础模型：$\theta^* = \theta_0 + \alpha \cdot \tilde{\delta}_{tgt}$。
