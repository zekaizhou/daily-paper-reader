## 摘要
诸如 CLIP 之类的大型预训练视觉-语言模型通过在共享特征空间中对齐图像和文本，彻底改变了计算机视觉领域，并通过提示（prompting）实现了鲁棒的零样本迁移。软提示（Soft-prompting）方法，如上下文优化（CoOp），通过学习一组上下文向量，有效地使这些模型适应下游识别任务。然而，CoOp 缺乏处理未知分布中领域偏移（domain shifts）的显式机制。针对这一问题，我们提出了领域不变上下文优化（DiCoOp），这是 CoOp 的一种扩展，专门针对领域泛化（domain generalization）进行了优化。通过采用对抗训练方法，DiCoOp 强制模型学习领域不变的提示，同时保留用于分类的判别能力。实验结果表明，在跨越不同视觉领域的领域泛化任务中，DiCoOp 的表现始终优于 CoOp。

## Abstract
Large pre-trained vision-language models like CLIP have transformed computer vision by aligning images and text in a shared feature space, enabling robust zero-shot transfer via prompting. Soft-prompting, such as Context Optimization (CoOp), effectively adapts these models for downstream recognition tasks by learning a set of context vectors. However, CoOp lacks explicit mechanisms for handling domain shifts across unseen distributions. To address this, we propose Domain-invariant Context Optimization (DiCoOp), an extension of CoOp optimized for domain generalization. By employing an adversarial training approach, DiCoOp forces the model to learn domain-invariant prompts while preserving discriminative power for classification. Experimental results show that DiCoOp consistently surpasses CoOp in domain generalization tasks across diverse visual domains.

*   **核心问题**：现有的提示学习方法（如 CoOp）缺乏显式的机制来处理未知分布。当模型在特定源域训练后，往往会捕捉到该域特有的偏见，导致其在未见的测试域（如从照片迁移到素描图）上泛化能力受限。
*   **研究目标**：设计一种能够学习“领域不变”特征的提示优化方法，使模型在保持分类准确性的同时，对输入数据的领域来源保持“无感”。

### 2. 论文提出的方法论：DiCoOp
*   **核心思想**：借鉴**领域对抗神经网络（DANN）**的思想，将对抗训练引入提示学习。通过引入**梯度反转层（GRL）**，在优化提示向量时，既要最小化分类损失，又要最大化领域分类器的损失，从而迫使提示向量剔除领域相关信息。
*   **关键技术细节**：
    *   **双重损失函数**：训练目标结合了分类损失（$L_{cls}$）和领域对抗损失（$L_{dom}$）。公式表达为：$L(v) = L_{cls}(v) - \lambda L_{dom}(v)$。其中 $\lambda$ 控制对抗强度的超参数。
    *   **梯度反转层（GRL）**：在反向传播时，GRL 会将领域分类器的梯度乘以 $-\lambda$，从而实现对抗学习。
    *   **三种提示策略**：
        1.  **SCP（共享上下文提示）**：所有提示词共同参与分类和领域对抗。
        2.  **DFP（领域优先提示）**：将提示词分为两半，前半部分负责领域信息，后半部分负责类别信息。优化领域时冻结类别词，反之亦然。
        3.  **CFP（类别优先提示）**：与 DFP 顺序相反，类别词在前，领域词在后。
*   **流程**：每次训练包含两次前向传播：一次用于类别预测（Class Pass），一次用于领域预测（Domain Pass）。推理时仅使用学习到的领域不变提示进行类别预测。
