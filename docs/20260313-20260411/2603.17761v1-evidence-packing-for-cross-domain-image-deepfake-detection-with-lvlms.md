## 摘要
图像深度伪造检测 (IDD) 通过识别合成或篡改的伪影，将操纵图像与真实图像区分开来。尽管大视觉语言模型 (LVLMs) 具有强大的图像理解能力，但将其应用于 IDD 通常需要昂贵的微调，且对多样化、不断演变的操纵方式泛化能力较差。我们提出了语义一致性证据包 (SCEP)，这是一种无需训练的 LVLM 框架，它用证据驱动的推理取代了全图推理。SCEP 挖掘出一组紧凑的可疑补丁标记 (patch tokens)，以最佳方式揭示操纵线索。它利用视觉编码器的 CLS 标记作为全局参考，将补丁特征聚类为连贯的组，并使用融合指标对补丁进行评分，该指标结合了 CLS 引导的语义不匹配以及基于频率和噪声的异常。为了覆盖分散的痕迹并避免冗余，SCEP 在每个聚类中采样少量高置信度补丁，并应用基于网格的非极大值抑制 (NMS)，生成一个证据包，用于引导冻结的 LVLM 进行预测。在多个基准测试上的实验表明，SCEP 在无需微调 LVLM 的情况下优于强基准模型。

## Abstract
Image Deepfake Detection (IDD) separates manipulated images from authentic ones by spotting artifacts of synthesis or tampering. Although large vision-language models (LVLMs) offer strong image understanding, adapting them to IDD often demands costly fine-tuning and generalizes poorly to diverse, evolving manipulations. We propose the Semantic Consistent Evidence Pack (SCEP), a training-free LVLM framework that replaces whole-image inference with evidence-driven reasoning. SCEP mines a compact set of suspicious patch tokens that best reveal manipulation cues. It uses the vision encoder's CLS token as a global reference, clusters patch features into coherent groups, and scores patches with a fused metric combining CLS-guided semantic mismatch with frequency-and noise-based anomalies. To cover dispersed traces and avoid redundancy, SCEP samples a few high-confidence patches per cluster and applies grid-based NMS, producing an evidence pack that conditions a frozen LVLM for prediction. Experiments on diverse benchmarks show SCEP outperforms strong baselines without LVLM fine-tuning.

*   **核心问题**：如何在不进行昂贵微调的情况下，利用大视觉语言模型（LVLM）实现高效、泛化性强的图像深度伪造检测（IDD）。
*   **研究背景**：
    *   现有的 IDD 方法若采用 LVLM，通常需要大量高质量的指令微调数据（如文本理由、问答对），且对新出现的伪造类型泛化能力差。

### 2. 方法论：语义一致性证据包（SCEP）
SCEP 是一种**无需训练（Training-free）**的框架，其核心思想是将“全图推理”转变为“关键证据驱动的推理”。
*   **语义聚类与锚定**：利用视觉编码器的 `CLS` token 作为全局语义参考，通过**球面 K-means 算法**将图像块（patch）聚类。这确保了后续的证据挖掘是在语义一致的区域内进行，避免模型被无关的背景语义干扰。
*   **多维异常评分（Fused Scoring）**：对每个图像块计算三个维度的分数：
    1.  **语义差异（Asem）**：计算 patch 与 `CLS` token 的余弦距离，识别语义不一致的区域。
    2.  **频率异常（Afreq）**：通过 2D 离散余弦变换（DCT）分析 patch 的频谱分布，利用 JS 散度（JSD）衡量局部频谱与全局平均频谱的偏差。
    3.  **噪声异常（Anoise）**：通过高斯平滑提取残差图，利用中值（Median）和中值绝对偏差（MAD）来捕捉合成过程中产生的局部噪声不一致性。
*   **证据打包与去冗余**：
    *   在每个聚类中选取 Top-k 的高分 patch。
    *   应用**基于网格的非极大值抑制（NMS）**，在空间上抑制冗余的相邻块，确保证据包具有跨区域的覆盖性。
*   **推理阶段**：将筛选出的“证据包”与特定提示词（Prompt）组合，输入冻结的 LVLM 得到最终的真伪判断。

### 6. 主要结论与发现
*   **性能提升**：SCEP 在所有测试的 LVLM 上均显著优于原始推理和通用的 Token 剪枝方法。在 Gemma-3 上，AI 生成图像检测的准确率提升尤为明显。
*   **跨域鲁棒性**：在 AI 编辑（局部篡改）任务中，SCEP 表现出极强的定位能力，能够精准捕捉到对象操作带来的细微异常。
*   **效率优势**：通过减少输入 LVLM 的 Token 数量，不仅提高了检测精度，还显著降低了计算开销和推理时间。

### 7. 优点（亮点）
*   **无需训练**：极大地降低了部署成本，能够直接适配任何现成的预训练 LVLM。
*   **物理与语义结合**：巧妙地将数字图像取证中的经典特征（频率、噪声）与现代 LVLM 的语义理解能力结合。
*   **证据驱动**：通过 NMS 和聚类确保了证据的多样性和代表性，解决了 LVLM 在处理长序列视觉 Token 时的注意力分散问题。

### 8. 不足与局限
*   **依赖视觉编码器**：该方法的效果高度依赖于冻结的视觉编码器（如 CLIP）提取特征的质量，如果编码器本身对某些新型伪造不敏感，SCEP 的评分机制可能失效。

*   **极端情况**：对于完全不改变频率分布和噪声特性的极高质量伪造（如某些纯神经渲染结果），仅靠目前的三个指标可能仍存在漏检风险。
