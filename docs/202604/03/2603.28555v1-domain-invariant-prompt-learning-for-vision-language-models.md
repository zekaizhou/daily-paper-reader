## 摘要
诸如 CLIP 之类的大型预训练视觉-语言模型通过在共享特征空间中对齐图像和文本，彻底改变了计算机视觉领域，并通过提示（prompting）实现了鲁棒的零样本迁移。软提示（Soft-prompting）方法，如上下文优化（CoOp），通过学习一组上下文向量，有效地使这些模型适应下游识别任务。然而，CoOp 缺乏处理未见分布中领域偏移（domain shifts）的显式机制。为解决这一问题，我们提出了领域不变上下文优化（DiCoOp），这是 CoOp 的一种针对领域泛化（domain generalization）进行优化的扩展。通过采用对抗训练方法，DiCoOp 强制模型学习领域不变的提示，同时保留用于分类的判别能力。实验结果表明，在跨越不同视觉领域的领域泛化任务中，DiCoOp 的表现始终优于 CoOp。

## Abstract
Large pre-trained vision-language models like CLIP have transformed computer vision by aligning images and text in a shared feature space, enabling robust zero-shot transfer via prompting. Soft-prompting, such as Context Optimization (CoOp), effectively adapts these models for downstream recognition tasks by learning a set of context vectors. However, CoOp lacks explicit mechanisms for handling domain shifts across unseen distributions. To address this, we propose Domain-invariant Context Optimization (DiCoOp), an extension of CoOp optimized for domain generalization. By employing an adversarial training approach, DiCoOp forces the model to learn domain-invariant prompts while preserving discriminative power for classification. Experimental results show that DiCoOp consistently surpasses CoOp in domain generalization tasks across diverse visual domains.

### 2. 方法论：DiCoOp
论文提出了 **DiCoOp (Domain-invariant Context Optimization)**，其核心思想是将**对抗训练**引入提示学习。
*   **核心思想**：借鉴领域对抗神经网络（DANN）的思路，利用**梯度反转层（GRL）**。在训练过程中，模型不仅要预测图像的类别，还要尝试预测图像所属的领域。通过 GRL，模型在优化领域预测损失时会反向更新提示向量，从而“抹除”提示向量中的领域信息，使其变得“领域不变”。
*   **关键技术细节**：
    *   **双路径训练**：每次迭代包含“类别通路”（最小化分类损失）和“领域通路”（通过 GRL 最大化领域分类损失）。
    *   **三种提示结构**：
        1.  **SCP (Shared Context Prompting)**：所有提示词 Token 共享，同时学习类别和领域不变特征。
        2.  **DFP (Domain-First Prompting)**：将提示词分为两半，前半部分负责领域不变性，后半部分负责类别判别。
        3.  **CFP (Class-First Prompting)**：与 DFP 顺序相反。在优化一类 Token 时，冻结另一类 Token。
*   **损失函数**：总损失 $L = L_{cls} - \lambda L_{dom}$，其中 $\lambda$ 控制对抗训练的强度。
